Module 8: Lab Activity – Booleans

About This Module

This module contains Python programming assignments focused on Boolean values, comparison operators, logical operators, and conditional statements.

Problems

Problem 1 – Compare Two Inputs

A function that takes two user inputs and checks whether they are equal.

Problem 2 – Sum Comparison

A function that checks whether the sum of two numbers is greater than, less than, or equal to 10.

Problem 3 – Check for a Value in a List

A function that checks whether the number 5 is present in a list.

Problem 4 – Leap Year

A function that determines whether a given year is a leap year and returns True or False.

Problem 5 – Game Character Tasks

A program that checks whether a game character has the required items and weaknesses to complete three tasks:

Climb a mountain

Cook a meal

Write a book
